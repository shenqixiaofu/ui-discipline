# ui-discipline

给 AI 编码助手用的技能：**把界面「好不好看」降级成可机械检查的规则**。

要解决的问题很具体——AI（和人）写界面时从不缺审美，缺的是 token。真正要防的不是「配色难看」，是**随手**：随手写个 `#0ea5e9`，随手写个 `13px`，随手给每个指标卡配一个色相。每一次都局部合理，合起来就散了。

## 核心判据

> 这个值是从已有 token 里选的，还是我临时想的？

- token 里有 → 直接用。
- 没有但确实需要 → **先补 token，再用它**。补 token 是一次决策，写裸值是 200 次决策。
- 只是「这样看着舒服」→ **不行**。
- 答不上来 → 默认用最近的那个 token。

## 硬规则（摘要）

| 维度 | 规则 |
|---|---|
| 颜色 | 禁止字面量，一律走变量；纯白 / `transparent` / `currentColor` 不算裸值 |
| 字号 | 只有 4 档：12 / 14 / 16 / 20，数据大数字单开 28。**最小 12px**，低于它用字重和颜色分层次 |
| 圆角 | 3 档：4 / 8 / 10，胶囊 `999px` 是第 4 种合法值。嵌套时内圆角 = 外圆角 − padding |
| 阴影 | 最多 2 档，且优先用边框。卡片默认「白底 + 0.5px 边框」，只有真浮起的元素给阴影 |
| 间距 | 必须落在 4 的倍数上——间距决定节奏，随手写个 13px 比色值更容易毁一致性 |
| 语义色 | 红 = 失败，绿 = 成功，黄 = 警告。**一个指标卡配一个色相不是语义，是装饰** |
| 布局 | 一行不超过 3 个按钮；第 4 个起收进「更多」，但不能静默藏 |
| 数字 | 右对齐 + `font-variant-numeric: tabular-nums`，位数不同还左对齐就没法竖着扫 |

另含：`0.5px` 在普通屏会消失的代价与替代写法、最小 token 结构、改存量页面的流程、13 条反模式、正反示例。

## 机械自检

不靠眼睛，靠脚本。扫四件事：裸色值数量、字阶档位、圆角档位、低于 12px 的字号。

**Tailwind 项目必看**：装了 shadcn / Tailwind 之后样式从 `.css` 搬进 `className`，写成 `bg-[#0ea5e9]`。只扫 `.css` 的脚本会报「裸色值 0」——**假阴性比不检查更危险**。技能里的脚本把两边合起来统计，并按职能拆开（字号 / 圆角 / 间距）。

还有一份只看 `package.json` 的重复依赖检查（`framer-motion` vs `motion`、`lucide-react` vs `@lucide/react` 这类并存问题）。

## 技术栈：默认选型与禁止清单

`shadcn/ui`（style `base-nova`）/ Lucide / Motion / `react-resizable-panels` / `dnd-kit` / Zustand，配一份带理由的禁止清单（为什么不选 antd、为什么不直接 `import @radix-ui/*`）。

> **仅 React 项目生效。** Vue 项目跳过这一节——shadcn/ui 和 Zustand 都不支持 Vue，不要照搬结论。Vue 项目只沿用上面的 token / 字号 / 圆角 / 反模式规则。

## 安装

复制到 agent 的技能目录即可：

```
cp -r ui-discipline ~/.workbuddy/skills/
```

适用于支持 `SKILL.md` + frontmatter（`name` / `description`）的 agent 框架。

## 来历

在一个 2.1 万行的移动端 H5（Vue，6 套主题各 38 个变量）上跑了一遍收口：

- 圆角裸值 **14 档 → 0**，字号裸值 **18 档 → 0**（收敛到 5 档，低于 12px 清零），阴影 **51 种 → 20**
- 288 处声明 1:1 换值，没动结构、没动组件逻辑
- 顺带挖出一个真 bug：6 套主题通过 `style.setProperty` 写 `<html>`，里面的 `--border-radius` 优先级高于 `:root` 的别名，token 在**运行时根本不生效**——只看 CSS 看不出来

这套规则是这么长出来的，不是先写规范再套项目。
